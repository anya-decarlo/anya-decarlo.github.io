Semantic Model: Reconciled Financial Statements

Companies tag the same number differently in their XBRL filings. This model maps those source tags onto one set of business definitions, links every value back to its filing, and documents the calculation logic. The result is a clean FY2024 dataset for every SEC filer.

1Source fields

Each business concept can come from several XBRL tags. Tags are tried in precedence order, and the first one a company reports wins. If none is reported, the concept is derived from other concepts where an accounting identity allows it. Reported by counts the companies that filed the tag. Used for counts the companies whose value came from it.

2Business definitions

The meaning of each concept, independent of how any company tagged it. Duration concepts cover the fiscal year. Instant concepts are measured at fiscal year-end.

3Relationships

How the model's entities connect, and the accounting identities that tie concepts together. The identities drive both the derivations and the quality checks.
