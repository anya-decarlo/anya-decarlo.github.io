💡 Key Insights

  • Smaller σ (observation SD) → Less noisy data → Higher precision → More certainty
  • Precision adds up: Posterior precision = Prior precision + Data precision
  • Variance decreases: As precision increases, posterior variance (τₙ²) decreases
