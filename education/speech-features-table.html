Lexical
(Diversity & Productivity)		 TOTAL_WORDS
nwords = Σi=1N 𝟙(tokeni ∉ punctuation)
MATTR_MEAN
(Moving-Average Type-Token Ratio)
MATTR = (1/m) Σj=1m (|Vj| / w)
where |Vj| = unique types in window j, w = 50 tokens, m = number of windows
TOTAL_PHONEME_MEAN
(Phonemes per Second)
rphoneme = (Σi=1n |Pi|) / T
where |Pi| = phoneme count for word i, T = duration (seconds)
TENSE_PRES
(Present Tense Verbs)
npres = Σi=1N 𝟙(morphi = "Tense=Pres")
Temporal
(Duration & Pauses)		 SPEAKING_DURATION_PRAAT
(Total Speech Time)
Tspeech = Σk=1K dk
where dk = duration of voiced segment k (intensity > 50 dB)
NONSPEECH_MEAN_SEC_PRAAT
(Mean Pause Duration)
μpause = (1/npause) Σj=1npause pj
where pj = duration of pause j (intensity < 50 dB, duration > 0.2 sec)
NUM_REG_PAUSES_STAND_PRAAT
(Standardized Pause Count)
npause,std = npause / Ttotal
Normalized pause count per unit time
PERC_SPEECH_PRAAT
(Percentage Speech Time)
%speech = (Tspeech / Ttotal) × 100
Ratio of voiced to total recording time
Acoustic
(Spectral & Prosodic)		 StddevUnvoicedSegmentLength
(Voice Quality Variability)
σunvoiced = √[(1/n) Σi=1n (Li - μ)²]
where Li = duration of unvoiced segment i
loudnessPeaksPerSec
(Prosodic Variability)
rpeaks = npeaks / Ttotal
where npeaks = local maxima in loudness contour (threshold: 3 dB above local mean)
spectralFlux
(Spectral Change Rate)
Φ = (1/M) Σt=1M √[Σk=1K (|Xt,k| - |Xt-1,k|)²]
where Xt,k = magnitude of frequency bin k at frame t, M = frames, K = frequency bins

Note: All features were extracted using automated pipelines. Part-of-speech tagging performed with spaCy (en_core_web_sm model). Acoustic features extracted via openSMILE with eGeMAPS feature set. Temporal features computed using Praat voice analysis toolkit. All features controlled for age, sex, and education in regression models. FDR correction applied via Benjamini-Hochberg method (q < 0.05).
